# Stock Portfolio Tracker - Quick Start Guide

## Installation & Running

### Backend
```bash
cd backend
npm install
npm run dev  # Starts on port 5000
```

### Frontend
```bash
cd frontend
npm install
npm start   # Starts on port 3000
```

## Testing the App

1. **Register** - Create a new account with credentials
2. **Search Stocks** - Find stocks like AAPL, GOOGL, MSFT, etc.
3. **Buy Stocks** - Purchase virtual stocks with your $100,000 balance
4. **Track Portfolio** - View your holdings and P&L
5. **Add to Watchlist** - Star your favorite stocks
6. **View Transactions** - See all your trade history

## Tech Stack Summary

- **Frontend**: React, Tailwind, Axios, Chart.js
- **Backend**: Node, Express, MongoDB, JWT, bcryptjs
- **Authentication**: JWT with Bearer tokens
- **Database**: MongoDB with Mongoose
